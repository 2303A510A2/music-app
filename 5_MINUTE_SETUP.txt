🆘 IF SOMETHING GOES WRONG
═══════════════════════════

Black window shows "npm: command not found"
→ Node.js not installed
→ Download from https://nodejs.org
→ Install it, restart computer, try again

Browser shows "Connection error"
→ Make sure black terminal window is still open
→ Make sure it shows "Server running..."
→ Try refreshing browser (Press F5)

Server won't start
→ Check if something else is using port 5000
→ Restart your computer
→ Try again
