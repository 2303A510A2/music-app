ERROR SCREENS (What NOT to See):
================================

Error 1: "Connection error. Make sure the backend server is running"
→ RED ERROR MESSAGE
→ This means server is NOT running
→ Go back to terminal and start it with: npm start

Error 2: "Port 5000 already in use"
→ RED ERROR in terminal
→ Another app is using port 5000
→ Close other apps or restart computer

Error 3: "Cannot POST /api/auth/register"
→ RED ERROR MESSAGE
→ Backend server crashed or not running
→ Check terminal for errors

Error 4: "Cannot find module"
→ ERROR in terminal
→ Run: npm install
→ Then: npm start


HOW TO TEST CONNECTION:
======================

Your browser automatically tests when you try to register/login.

If you want to manually test:
1. Make sure server is running (terminal shows "Server running...")
2. Go to: http://localhost:5000/test.html
3. It will show if backend is reachable

If page loads = Backend is working ✓
If page shows error = Backend is not running ✗

TROUBLESHOOTING CHECKLIST:
=========================

Can't see login page:
  ☐ Server is running (terminal shows "Server running...")?
  ☐ URL is correct: http://localhost:5000 (not https)?
  ☐ Try refreshing browser: Press F5
  ☐ Try clearing browser cache: Ctrl+Shift+Delete

Getting "Connection error" on register:
  ☐ Terminal is still open and shows server running?
  ☐ Are you using correct URL: http://localhost:5000?
  ☐ Try refreshing: Press F5
  ☐ Restart server: Close terminal, run npm start again

Can't register:
  ☐ All fields filled?
  ☐ Password is 6+ characters?
  ☐ Password matches confirm password exactly?
  ☐ Server running (check terminal)?

Can't login:
  ☐ Using correct email?
  ☐ Using correct password?
  ☐ Email and password match what you registered?
  ☐ Server running?

Dashboard not showing:
  ☐ Logged in successfully (saw success message)?
  ☐ Wait a moment for page to load
  ☐ Try refreshing: Press F5
