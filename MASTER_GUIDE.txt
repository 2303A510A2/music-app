SECTION 1: OPEN TERMINAL
═════════════════════════

What is Terminal?
─────────────────
Terminal is a black window where you type commands.
It's like talking to your computer in a special language.

How to Open Terminal:
─────────────────────
Method 1 (Fastest):
  1. Press Windows Key + R
  2. Type: cmd
  3. Press Enter
  → Black terminal window appears

Method 2 (Alternative):
  1. Click Windows Start button
  2. Search for: Command Prompt
  3. Click it
  → Terminal opens

You should see something like:
  C:\Users\YourName>


SECTION 2: NAVIGATE TO PROJECT FOLDER
═══════════════════════════════════════

Why?
───
The terminal starts in a default folder.
You need to go to where your "my music" project is.

How to Do It:
─────────────
Copy this EXACTLY:

  cd Desktop\"my music"

Then:
1. Right-click in terminal window
2. Click Paste
3. Press Enter

The path should change. You'll see "my music" in it.

Example:

The terminal window MUST stay open while you use the app.

─────────────────────
"npm install" only needs to happen FIRST TIME.
After that, just run "npm start"

First time:
  npm install && npm start

Every other time:
  npm start

──────────────────────
Never press Ctrl+C while using the app.
Press Ctrl+C only when you're completely done.

❌ ERRORS & SOLUTIONS
══════════════════════

Error 1: "npm: command not found"
──────────────────────────────────
Means: Node.js is not installed

Solution:
1. Download Node.js from: https://nodejs.org
2. Download LTS (Long Term Support) version
3. Run installer
4. Restart your computer
5. Try again


Error 2: "Port 5000 already in use"
────────────────────────────────────
Means: Another app is using port 5000

Solution:
1. Close other applications
2. Restart your computer
3. Try again


Error 3: "Cannot find module"
──────────────────────────────
Means: npm install didn't complete properly

Solution:
1. Run: npm install
2. Wait for it to finish
3. Then: npm start


Error 4: "Connection error. Make sure backend server is running"
────────────────────────────────────────────────────────────────
Means: Server is not running or not reachable

Solution:
1. Check terminal window
2. Make sure you see "Server running on http://localhost:5000"
3. If not, start server again: npm start
4. Make sure you're using: http:// (not https://)
5. Try refreshing browser: Press F5


Error 5: "Cannot POST /api/auth/register"
───────────────────────────────────────────
Means: Server crashed or endpoints not working

Solution:
1. Check terminal for error message
2. Close terminal (Ctrl+C)
3. Delete: backend/mymusic.db file
4. Run: npm start again
