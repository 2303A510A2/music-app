Backend Server Setup Guide

❌ The Problem

You're seeing: "Connection error. Make sure the backend server is running on http://localhost:5000"

This means the backend server is NOT RUNNING.

✓ The good news: It's easy to fix! Just follow the steps below.

⚡ QUICKEST WAY (Recommended)

🤖 Automatic

Let the script do everything

  1. Find and double-click:
    INSTALL_AND_RUN.bat
  2. Wait for installation
  3. Server starts automatically

⌨️ Manual

Full control and understanding

  1. Open Command Prompt
  2. Navigate to project
  3. Run commands below

📋 Manual Steps (3 Simple Steps)

1
Open Command Prompt (Terminal)
  • Press: Windows Key + R
  • Type: cmd
  • Press: Enter
2
Navigate to Project Folder

Type this command and press Enter:

cd Desktop\"my music"

Note: The quotes are important because of the space in "my music"

3
Install Dependencies & Start Server

Type this command and press Enter:

npm install && npm start

This will:

  • Install required packages (first time only, takes 1-2 minutes)
  • Start the backend server automatically
  • Show: Server running on http://localhost:5000
✓ After step 3, open your browser and go to: http://localhost:5000

⚠️ IMPORTANT: DO NOT CLOSE THE TERMINAL!

The terminal window MUST stay open while you use the app.

When you're done using the app, press Ctrl+C to stop the server.

✓ Verify It's Working

After running "npm start", you should see these messages in the terminal:

Connected to SQLite database
Users table ready
Playlists table ready
Songs table ready
Server running on http://localhost:5000
Press Ctrl+C to stop the server

If you see all these messages, your server is running! ✓

Next: Go to your browser and visit:

http://localhost:5000

🔧 If You Get Errors

Error: "npm: command not found"
Node.js is not installed. Download from https://nodejs.org, install it, restart your computer, and try again.
Error: "cd: command not found"
You might be using PowerShell. Close it and use Command Prompt (cmd) instead.
Error: "Port 5000 already in use"
Another app is using port 5000. Close other applications and try again, or restart your computer.
Still getting "Connection error"
Make sure you see "Server running on http://localhost:5000" in the terminal. If not, npm install might still be running. Be patient or close and try again.
Error: "Cannot find module"
Run npm install again. Sometimes it doesn't complete on first try.
