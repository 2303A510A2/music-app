START YOUR BACKEND SERVER - SUPER SIMPLE STEPS
════════════════════════════════════════════════════════════════

WITHOUT THIS STEP, NOTHING WILL WORK!
The "Connection error" means the server is not running.


⚡ THE EASIEST WAY - DOUBLE CLICK A FILE
═════════════════════════════════════════

Look for this file in your "Desktop\my music" folder:

    INSTALL_AND_RUN.bat

Just DOUBLE-CLICK it!

Wait for:
- Command window to open
- Many messages to appear
- See: "Server running on http://localhost:5000"

DONE! Server is running!

Then open browser: http://localhost:5000


✋ IF THAT DOESN'T WORK - MANUAL WAY
═════════════════════════════════════

Step 1: Press Windows Key + R
        Type: cmd
        Press Enter
        (A black window opens)

Step 2: Copy this and paste in the window:
        cd Desktop\"my music"
        Press Enter

Step 3: Copy this and paste in the window:
        npm install && npm start
        Press Enter

Step 4: WAIT! First time takes 1-2 minutes...
        Watch for: "Server running on http://localhost:5000"
        
        When you see that message = SUCCESS ✓


Step 5: Open your browser
        Go to: http://localhost:5000
        
        You should see login page


Step 6: NOW YOU CAN:
        - Click "Sign up"
        - Enter your name, email, password
        - Click "Create Account"
        - See: "✓ You have created account successfully!"
        - Redirected to login
        - Enter your email and password
        - Click "Log In"
        - See: "✓ I have been logged in successfully!"
        - Go to dashboard with playlists


⚠️  VERY IMPORTANT:
═══════════════════

DO NOT CLOSE THE BLACK TERMINAL WINDOW!

It must stay open the entire time you're using the app.

When done using app:
- Press Ctrl + C in the terminal
- Type: Y
- Press Enter
- Then close it


WHAT YOU'LL SEE IN TERMINAL:
═════════════════════════════

After Step 3, you should see (in order):

> my-music-app@1.0.0 start
> node backend/server.js
Connected to SQLite database
Users table ready
Playlists table ready
Songs table ready
Server running on http://localhost:5000
Press Ctrl+C to stop the server

If you see all this = PERFECT! ✓ Server is running!


NEXT TIME (MUCH FASTER):
════════════════════════

You don't need "npm install" next time!

Just do:
1. Open terminal (Windows Key + R, cmd, Enter)
2. Go to folder: cd Desktop\"my music"
3. Start: npm start
4. Wait for "Server running..." message
5. Open browser: http://localhost:5000


IF SOMETHING GOES WRONG:
═════════════════════════

"npm: command not found"
→ Node.js not installed
→ Download from https://nodejs.org
→ Install it
→ Restart computer
→ Try again

"Port 5000 already in use"
→ Close other applications
→ Or restart computer

Still getting "Connection error"
→ Make sure terminal shows "Server running on http://localhost:5000"
→ Make sure terminal window is still open
→ Try refreshing browser (Press F5)
